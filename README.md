## 🌐 ACESSO AO PROJETO

🔗 **Site oficial:** https://rocket-tech-pearl.vercel.app/

A Rocket Tech é um projeto voltado à criação de soluções digitais personalizadas, combinando desenvolvimento, design e tecnologia para ajudar empresas a fortalecer sua presença digital e otimizar processos.

## ⚡ SOBRE O PROJETO

O objetivo da Rocket Tech é desenvolver soluções digitais que unem funcionalidade, experiência do usuário e identidade visual.

Cada projeto é pensado para atender às necessidades de um negócio, desde a apresentação da marca até a criação de sistemas e integrações personalizadas.

**Nossa missão:** transformar ideias em soluções digitais funcionais, modernas e preparadas para evoluir.

## 🛸 FUNCIONALIDADES

- **🌌 Design responsivo:** experiência adaptada para computadores, tablets e smartphones.
- **💻 Serviços digitais:** apresentação dos serviços oferecidos pela Rocket Tech.
- **🧩 Projetos em destaque:** portfólio com trabalhos publicados.
- **📡 Formulário de contato:** canal para solicitar orçamentos e apresentar novas ideias.
- **💬 Integração com WhatsApp:** acesso rápido ao contato comercial.
- **♿ Recursos de acessibilidade:** opções de contraste, tamanho do texto e legibilidade.
- **🌍 Multilíngue:** opções de idioma em português, inglês e espanhol.
- **🚀 Deploy online:** aplicação publicada por meio da Vercel.

## 💻 COMO EXECUTAR LOCALMENTE

Para executar o projeto no seu computador:

**1. Clone o repositório**

```bash
git clone https://github.com/lucasmechinha123/Rocket-Tech.git
```

**2. Entre na pasta**

```bash
cd Rocket-Tech
```

**3. Instale as dependências**

Se o projeto utilizar Node.js e possuir um arquivo `package.json`, execute:

```bash
npm install
```

**4. Inicie o projeto**

Consulte os scripts disponíveis no `package.json` para identificar o comando correto de desenvolvimento, como `npm run dev` ou `npm start`.

> Se o projeto for HTML, CSS e JavaScript sem um ambiente Node.js, abra o arquivo HTML principal ou utilize um servidor local compatível.
